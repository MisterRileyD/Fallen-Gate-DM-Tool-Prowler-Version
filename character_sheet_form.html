Fallen Gate Character Sheet Form

Upload to Send @misterrileyd on the server a message. and MisterRileyD will import it to the character sheet index.

Edit / Load Existing Character Sheet

Use this if someone already has a character sheet file. It will fill in the form and re-check the spells and warrior skills that sheet already has.
Works with files using registerFallenGateCharacterSheet("CODE", {{...}}); or older window.FALLEN_GATE_CHARACTER_SHEETS = {{...}} format.

Generate Character Sheet File

Manifest line will appear here after generating.
Auto-updates after you change fields. After loading an old sheet, edits to rank, stats, spells, skills, race, inventory, and notes will rebuild the clean JS output automatically. To update an old player sheet: load the old .js file, make changes, click Generate Clean JS Sheet, then replace the entire old .js file with this cleaned output. Do not paste the new code under the old code.
