Fallen Gate Character Sheet Form

Fill this out, check the spells and warrior skills, then generate the character sheet JS file.
Upload to https://discord.com/channels/1153395278016163840/1517229941006274710 and MisterRileyD will import it to the character sheet index.

Edit / Load Existing Character Sheet

Use this if someone already has a character sheet file. It will fill in the form and re-check the spells and warrior skills that sheet already has.
Works with files using registerFallenGateCharacterSheet("CODE", {{...}}); or older window.FALLEN_GATE_CHARACTER_SHEETS = {{...}} format.
