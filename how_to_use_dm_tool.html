How to Use DM Tool

Quick Guide

Open the Tome

Starting
  • Click the closed book cover on the first screen.
  • The book opens and loads the battle map with the encounter roster.
  • Use the Event Name box to name the encounter before sending it to Discord.

Add Player / Enemy

Roster
  • Type a name in the roster row.
  • Choose a rank, dragon, or monster from the Type dropdown.
  • Monster options are grouped by category so you can see where each one belongs.
  • Body, Mind, Spirit, AC, and Combat Mod fill from the selected type.
  • Use Add Sheet Code to add a saved character sheet by code.

Turn Order

Initiative
  • Set an Init Roll for each combatant.
  • Only combatants with a selected type and initiative join the active turn order.
  • Click Next Turn to move the current turn to the bottom.
  • If Body, Mind, or Spirit reaches 0, that combatant is treated as defeated.

Guide Books

Tabs
  • Right tabs open Monster Guide, Spellbook, Warrior Skills, and Character Sheets.
  • Left tabs open Dice System and How to Use DM Tool.
  • Use Close Book to hide the secondary book and return the main tome to full size.

Character Sheet Features

Character Sheets
  • Sheet Form: opens the character sheet form.
  • New Sheet: fill in basic character info, stats, jewelry, weapons, notes, spells, and warrior skills.
  • Edit / Load Existing Sheet: load an older .js character sheet or pick a sheet already listed in character_sheets_manifest.js.
  • Auto Check: when editing a sheet, the form tries to re-check the matching spells and warrior skills so you do not have to click them all again.
  • Generate JS Sheet: creates the character sheet code.
  • Copy Output: copies the finished code so it can be saved or posted.
The static website cannot save character sheet files by itself. The form creates the code, then the code must be added to the site files later.

Making or Editing Character Sheets

Step by Step
  1. Open the Character Sheets book.
  2. Click Sheet Form.
  3. For a new character, fill in the form from blank.
  4. For an old character, use Edit / Load Existing Character Sheet.
  5. Choose an already uploaded sheet from the list, or use the file picker to load an older .js sheet.
  6. Update the character's Body, Mind, Spirit, Combat Bonus, jewelry, weapons, notes, spells, and warrior skills.
  7. Click Generate JS Sheet.
  8. Click Copy Output.
  9. Post the copied code to the character sheet Discord channel for it to be added to the DM Tool.

Race Guide and Race Abilities

Character Sheet Help

Use the Race Guide tab to look up race abilities. In the Character Sheet Form, choose a race under Race and Race Abilities. The form will load that race's default abilities and save the checked ones into the generated character sheet file.

Copy Loot Split Button

Encounter Loot Help

The Copy Loot Split button is now in two places: directly beside Show / Divide Loot, and directly under the loot output box.

Use it like this: click Show / Divide Loot, confirm the loot appears in the loot box, then click Copy Loot Split.

Copy Turn Summary includes the latest successful loot split at the bottom of the turn summary. This also means Send / Update Discord includes the loot split because it uses the same summary text.

Updating an Existing Character Sheet

Character Sheet Help

To update an older player sheet, open the Character Sheet Form and load the old .js file using the edit/load option. The form will pull the old character data into the fields.

Make the changes you need, then click Generate Clean JS Sheet. The output box creates one clean replacement file using registerFallenGateCharacterSheet("CODE", {...});.

Use Download / Replace JS File to download the updated file, or use Copy Clean JS Code and replace the entire old character sheet file with the output. Do not paste the new code underneath the old code.

The manifest line should stay the same if the file name stays the same. Example: "./Lucie.js".

Auto-Updating Character Sheet Output

Character Sheet Help

After loading an older character sheet, the output box now rebuilds automatically when you change fields, check or uncheck spells, skills, race abilities, inventory, or notes.

If the output ever looks old, click Force Rebuild Output. Then use Copy Clean JS Code or Download / Replace JS File.

To update a player sheet, replace the entire old .js file with the clean output. Do not add the new output under the old output.

Spell Updates and Multiline Spell Costs

Character Sheet Help

Some spells, especially Summoning spells, have long costs with multiple lines. The Character Sheet Form now reads those spell checkboxes safely, so checked Summoning spells are included when you generate or rebuild a character sheet.

If a spell does not appear in the output, click Force Rebuild Output. The output count line will show total spells and how many Summoning spells are included.

Warrior Skills on character sheets now show the skill discipline and tier in parentheses, such as Improved Critical (Slashing — Soldier) or Improved Critical (Piercing — Soldier).

Monster Guide Roster Button and Auto Discord Turn Updates

Encounter Tool Help

Each monster page in the Monster Guide now has an Add Monster to Roster button. Open the Monster Guide inside the DM Tool, go to a monster page, then click the button to add that monster directly into the encounter roster.

The added monster starts with its monster type, Body, Mind, Spirit, AC, Bonus, and category effects filled in. Add its Init Roll when it enters combat.

The Next Turn button now auto-updates the existing Discord post after the turn changes. You must send the first Discord post with Send / Update Discord first so the tool has a Discord Message ID. After that, Next Turn edits that saved post without making a new one.

Monster Guide Add to Roster Button

Encounter Tool Help

Each monster page has an Add Monster to Roster button. The button now uses a safe hidden monster-name field, so monster names with parentheses or special symbols will not break the button.

Open the Monster Guide from inside the DM Tool, choose a monster, then click Add Monster to Roster. The monster should appear in the encounter roster with stats filled in. Add its Init Roll when it enters combat.

Map Designer and Local Map Saves

Map Help

The encounter map now has a small map designer. You can upload a background image, add simple map items like walls, doors, chests, traps, pillars, trees, and labels, then keep using the same map for tokens.

Save Map to This Browser stores the map on the current person's computer/browser using browser storage. It does not save the map to the online tool or to other players.

Download Map File saves a .fgmap.json file to the person's computer. Use Load Map File later to bring it back. This is the safest way to keep a map outside the tool.

Browsers cannot secretly save files into a chosen folder. The user must either download the map file, load a map file, or use the browser's local save.

Adding Visible Map Items

Map Help

To place map items, click a tool such as Add Wall, Add Door, Add Chest, Add Trap, Add Pillar, Add Tree, or Add Text, then click directly on the map grid.

The map tool now places visible labeled items on the canvas. Use Add Sample Items to quickly test that map items are drawing.

Use Move Tokens when you want to drag player or monster tokens again. Map items save with Save Map to This Browser or Download Map File.

Mortal Race

Race Guide Help

The Mortal race is available in the Race Guide and Character Sheet Form. It is used for normal mortal/common characters or characters without a special race ability package.

It has one placeholder entry, No Innate Race Ability, so the character sheet can still record that the player chose Mortal as their race.

Mortal in Character Sheets

Character Sheet Help

The Character Sheet Book now shows Mortal as the race for any older player sheet that does not have a race saved yet.

The Character Sheet Form also defaults blank or older sheets to Mortal, so when you regenerate the sheet, the saved JS file will include race: "Mortal", raceFamily: "Mortal / Common Race", and raceTier: "Base".

Mortal Race Dropdown

Character Sheet Form Help

Mortal is now listed in the Character Sheet Form under Race and Race Abilities. It appears near Immortal so it is easier to find.

Choosing Mortal adds the placeholder race ability No Innate Race Ability, allowing the sheet to record normal mortal/common characters.

Character Sheet Image Uploads

Character Sheet Help

The Character Sheet Form now has optional uploads for a Profile Picture and an ID Image. These images are saved inside the generated character sheet JS file as image data.

When that character sheet is listed in the Character Sheet Book, the profile picture and ID image will display near the top of the character page.

Large images can make a character sheet JS file very large. Smaller PNG, JPG, or WebP images are recommended.

Moving Map Items

Map Help

Use Move Tokens to drag player or monster tokens.

Use Move Map Items to drag placed map items like walls, doors, chests, traps, pillars, trees, and text labels.

After moving map items, use Save Map to This Browser or Download Map File to keep those map item positions.

Discord Link Setup

Discord Help

The Discord webhook now lives in discord_config.js. Paste the webhook URL in that file so future index.html updates do not wipe the Discord link.

If you do not see a new Discord post, check two things: first, the webhook must be pasted into discord_config.js; second, if a Discord Message ID is saved, Send / Update Discord edits that existing post instead of making a new one.

To make a brand-new post, click Start New Discord Post, then click Send / Update Discord.

Compact Roster and Easier Token Grab

Encounter Tool Help

The Encounter Data roster now uses a smaller compact layout so the table fits better without inner scrolling. When a second book is open, the roster text becomes smaller again to fit the tighter space.

Move Tokens now has a larger grab area around player and monster tokens. You can click near the token instead of exactly on the circle.

Move Map Items now has a larger grab area around walls, doors, chests, traps, pillars, trees, and labels. Grab hints appear on the map while a move tool is selected.

Evened Roster Table

Encounter Tool Help

The roster table has been polished so the columns look more centered and evenly spaced. Stat columns, AC, Bonus, Init, Loot, and Remove are centered, while Name, Type, and Effects stay left-aligned for readability.

The roster also has cleaner row spacing, subtle alternating rows, and hover highlighting to make each row easier to follow.

Sheet Links, Roster Fit, and Map Item Size

Update Help

Character Sheets: The Add This Sheet to Encounter button is now near the top of each character sheet page. Spells and warrior skills on a character sheet are clickable; clicking one opens the Spellbook or Warrior Skills book and searches for that entry.

Encounter Roster: The roster uses shorter headers, shorter status labels, and adjusted column widths so the row data is easier to read without an inner table scrollbar.

Map Items: Map items can now be created at a chosen size. Use Item Size before placing a wall, door, chest, trap, pillar, tree, or text. Use Move Map Items to select an item, then use Grow Selected or Shrink Selected to resize it.

Stats, Edge Placement, and Exact Sheet Links

Update Help

Roster Stats: The Body, Mind, Spirit, AC, Bonus, and Init cells were widened and made bolder so the numbers are easier to read.

Map Edge Placement: The large grab hint circles were removed from the map view. Moving tokens and map items now clamps to the map edge, making it easier to place things on the border of the grid.

Character Sheet Links: Clicking a spell or warrior skill now searches for the exact item-title first, so it opens the spell or skill page instead of only the spell book, magic type, or discipline section.

The Encounter Data roster table font has been increased by about 7px. This affects the roster headers, stat numbers, dropdowns, status labels, and remove button.

When a second book is open, the roster still uses a slightly smaller font so it has a better chance to fit in the reduced space.

Wider Roster with Secondary Book

Encounter Data Help

When a secondary book is open, the Encounter Data book now keeps more width and the secondary book becomes smaller. This helps the roster keep its Name, Type, stats, and Effects data visible instead of squeezing the fields too much.

The roster column widths were also rebalanced so Type and Effects have more room while Body, Mind, Spirit, AC, Bonus, Init, Loot, and Delete stay readable.

Balanced Secondary Book Layout

Layout Help

The previous layout made the secondary book too narrow and cut off a lot of its content. This update restores a balanced two-book view.

The secondary book is wider again, the main Encounter Data book is only slightly scaled down, and the roster keeps a compact readable font when another book is open.

On smaller screens, the books stack instead of squeezing side-by-side, which prevents the roster and character sheet from being cut off.

Map / Layout Help

The two-book view has been nudged closer together so the secondary book is not pushed so far right, while still keeping the secondary book wide enough to read.

The Battle Map now has a Delete Map Item tool. Choose it, then click near a wall, door, chest, trap, pillar, tree, or text label to remove it.

You can also use Move Map Items to select an item, then click Delete Selected.

More Space Between Books

Layout Help

Layout Help
